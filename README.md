# Oerjan Hoel Portfolio



## Structure
- `index.html`: homepage
- `css/style.css`: custom styles
- `js/script.js`: theme, counters, form demo
- `projects/`: project detail pages
- `blog/`: blog article pages
- `assets/`: downloadable résumé placeholder

Bootstrap and Bootstrap Icons are loaded from a CDN, so an internet connection is required for those resources.
